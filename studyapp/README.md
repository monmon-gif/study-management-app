# Study Management App

JavaScript / Next.js と Java / Spring Boot を使った学習管理アプリです。

## 使用技術

- Next.js
- JavaScript
- Spring Boot
- Java 17
- Spring Data JPA
- PostgreSQL
- Supabase
- Tailwind CSS

## 機能

- 学習タスクの一覧表示
- 学習タスクの追加
- 完了 / 未完了の切り替え
- タスク削除
- Supabase PostgreSQL への保存

## 構成

```txt
frontend  : Next.js
studyapp  : Spring Boot API
Supabase  : PostgreSQL
